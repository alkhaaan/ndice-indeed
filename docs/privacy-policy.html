NDice Indeed Privacy Policy

Effective date: May 22, 2026

NDice Indeed ("we", "our", "us") provides a Chrome extension to help users autofill supported Dice job application workflows with review-first controls.

What we collect

NDice Indeed does not require account creation and does not collect personal data to our servers by default.

The extension stores data locally in your browser, such as:

  • profile autofill fields you enter
  • extension settings
  • automation activity logs
  • job processing history

How data is used

Data is used only to:

  • autofill supported form fields on Dice pages
  • show logs and run history to the user
  • support extension settings and scheduling behavior

Data sharing

We do not sell your personal data.

We do not share your locally stored extension data with third parties for advertising.

Remote transmission

At this time, NDice Indeed does not use external analytics or remote servers for user data processing in the extension codebase.

Permissions use

  • storage: save settings, logs, and history locally
  • alarms: schedule runs
  • tabs: open and process job tabs
  • scripting: run logic on supported pages
  • https://*.dice.com/*: operate only on Dice pages

User control

You can edit or remove saved profile data from the extension popup, and clear extension data by removing the extension from Chrome.

Security

We apply reasonable safeguards and keep the extension scope limited to supported Dice pages.

Children

NDice Indeed is not intended for children under 13.

Changes to this policy

We may update this policy. Updates will be reflected by a new effective date.
